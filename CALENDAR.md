# Terraform Complete Learning Calendar — 60 Days

## Calendar

**Recommended cadence:** Monday–Saturday study, Sunday review/catch-up. If you prefer every day, use Sunday for the week's quiz and revision.

| Week | Days | Theme | Main Outcome |
|---|---|---|---|
| 1 | 1–6 | Foundations | IaC, Terraform architecture, CLI, HCL, providers, resources, variables, outputs |
| 2 | 7–12 | Language Mastery | Types, expressions, collections, functions, dynamic blocks, data sources, dependencies |
| 3 | 13–18 | State & Modules | State internals, backends, locking, workspaces, modules, module contracts, refactoring |
| 4 | 19–24 | AWS Networking | VPC, CIDR, subnets, routing, NAT, endpoints, security groups, NACLs, DNS |
| 5 | 25–30 | AWS Compute & Data | EC2, IAM, ALB, Auto Scaling, S3, RDS, ElastiCache, Lambda |
| 6 | 31–36 | Containers & Kubernetes | ECS, ECR, Fargate, EKS, node groups, IRSA, load balancing |
| 7 | 37–42 | Production Engineering | Remote state, environments, CI/CD, testing, linting, security, policy, cost |
| 8 | 43–48 | Operations | Drift, import, moved blocks, lifecycle, recovery, debugging, upgrades, disaster recovery |
| 9 | 49–54 | Enterprise | Multi-account, multi-region, provider aliases, landing zones, governance, private modules |
| 10 | 55–60 | Capstones & Interviews | Production projects, architecture reviews, troubleshooting, scenario interviews || 10 | 55–60 | Capstones & Interviews | Production delivery + interview readiness |

## Weekly Rhythm

- **Day 1–5:** Learn + build.
- **Day 6:** Integration lab / mini project.
- **Day 7:** Review, quiz, flashcards, interview practice and cleanup.
- Every day: **notes → example → practical → break/fix → interview Q&A → diagram**.

## Completion Gates

- **Gate 1 (Day 14):** Write Terraform without copying beginner tutorials.
- **Gate 2 (Day 24):** Explain state, modules, import and refactoring.
- **Gate 3 (Day 40):** Build AWS application platforms.
- **Gate 4 (Day 50):** Operate Terraform safely in CI/CD.
- **Gate 5 (Day 60):** Design and defend a production architecture.
