# Day 02 — CLI Workflow

**Build:** run the complete CLI lifecycle in the local lab: init, fmt, validate, plan, show, output, state list and destroy.

**Break/fix:** save a plan with `-out`, change an input, and compare it with the saved plan.

**Production:** require review between plan and apply; use `-replace` deliberately and avoid routine `-target`.

**Interview:** explain `-out`, `-refresh-only`, `-replace`, and `-target`.

**Exit:** perform a safe end-to-end run without notes.
