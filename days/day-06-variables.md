# Day 06 — Variables

**Build:** add typed variables, defaults and validation to the S3 lab.

**Break/fix:** provide an invalid bucket name or region and trace the validation failure.

**Production:** keep environment-specific inputs outside reusable module code; never put secrets in committed tfvars.

**Interview:** variable vs local, sensitive variables, secret-management choices.

**Exit:** use strong types and at least one validation rule.
